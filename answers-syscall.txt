4. Write down the assembly instruction the kernel is panicing at. Which register corresponds to the variable num? 
    num = *(int *)0;
    80001cf8:	00002683          	lw	a3,0(zero) # 0 <_entry-0x80000000>

    <address>: <machine code> <decoded instruction>
    Explain instruction:
        lw → load word (32-bit)
        a3 → destination register (x13)
        zero → register x0, which is hard-wired to 0
        0(zero) → memory address 0 + 0 = 0x0
        => it means load a 32-bit word from memory address 0x00000000 into register a3

        RISC-V lw instruction format (I-type):
        
                      imm[11:0]  | rs1  | funct3 |  rd | opcode
                        12 bits  |  5   |   3    |  5  |   7
        0x00002683 = 000000000000  00000   010    01101 0000011

        Opcode 0x03 = LOAD instructions
        funct3 0x02 = LW (load word)
        Register x13 → a3
        Register x0 → zero
        Offset (imm[11:0]) = 0
        => decoded instruction: lw a3, 0(zero)

        80001cf8 = Program Counter (PC) value
